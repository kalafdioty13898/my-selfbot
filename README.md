# 🤖 سلف‌بوت شخصی من (نسخه ۱)

سلف‌بوت Telethon با ۱۰ ماژول، پنل راهنمای کامل، پشتیبانی **چند اکانت** و اجرای رایگان روی **GitHub Actions**.

---

## ✨ قابلیت‌ها

| ماژول | دستورهای اصلی |
|-------|----------------|
| 💾 مدیا | `ذخیره` (ریپلی) — `دریافت استوری @user` — `ذخیره خودکار` در هر چت: مدیای تایم‌دار بدون ریپلی خودکار ذخیره می‌شود (`ذخیره خودکار @کانال` برای انتخاب مقصد، `ذخیره خودکار خاموش/لیست`) — `سیو چنل` هر پست جدید کانال خودکار فوروارد می‌شود (`سیو چنل @کانال`، `سیو چنل خاموش/لیست`) |
| 🛡 آنتی‌حذف | `ذخیره حذف روشن` — `ذخیره ویرایش روشن` — `تنظیم ریلم` (در چت مقصد) — گزارش فقط چیزهای مرتبط: پیوی همه؛ گروه‌ها فقط اگر منشن تو باشند یا ریپلای به پیام خودت |
| 🤖 منشی | `تنظیم منشی` (ریپلی یا متن جلوی دستور) — `منشی آنی روشن` (همیشه فوری جواب می‌دهد) — `منشی افلاین روشن` (وقتی آنلاین نیستی جواب می‌دهد) — `منشی تگ روشن` (جواب منشن در گروه‌ها) — `منشی هوشمند روشن` — `تنظیم منشی افلاین 10` — `تنظیم زمان منشی 5` — `وضعیت منشی` — لیست سیاه |
| ⚡ پاسخ سریع | `پاسخ 'سلام' خوبم` — روی مدیا ریپلی + `پاسخ 'کلمه'` → جواب مدیایی — `پاسخ ها` — `حذف پاسخ` |
| 👤 پروفایل | `اسم جدید` — `اسم روشن` — `اسم ها` — `بیو جدید` — `بیو روشن` — `ساعت اسم روشن/خاموش` — `ساعت بیو روشن/خاموش` (ساعت زنده ⌚ + متغیر `TIME`, `DATE`, `RANDNUM1-99`) |
| 👥 گروه | `قفل عنوان روشن` — `قفل عکس روشن` — `سکوت روشن` / `سکوت همه 30` — `فیلتر کردن` — `تگ` / `تگ مدیران` / `لغو تگ` — `پاکسازی عکس ها` و… — `تنظیم خوش امدگویی` — `اخراج` — `لینک گروه` — `شناسه گروه` |
| ⏰ یادآور | `یادآور 30 متن` — `هشدار جدید 21:30 متن` — `حذف خودکار 5` (ریپلی) — `حذف روشن 5` (کل پیام‌های من در چت) |
| 🌐 ترجمه/وایس | `ترجمه en` (ریپلی) — `وایس سلام` یا ریپلی + `وایس` — وایس فارسی با صدای طبیعی (edge-tts)؛ کد زبان اختیاری: `وایس en hello` |
| ☁️ ابری | `ذخیره محتوا اسم` (ریپلی) — `دریافت محتوا اسم` — `لیست ذخیره` |
| ⚙️ عمومی | `پنل` (عکس پروفایل + منوی شماره‌ای بخش‌ها — `پنل 2` یا `پنل منشی`، وضعیت: `پنل وضعیت`) — `وضعیت` — `پینگ` — `ست لاگ` (مقصد همه لاگ‌ها/ذخیره‌های خودکار: `ست لاگ @چت`، `ست لاگ تست`، `ست لاگ خاموش`) — `سلف خاموش/روشن` — `سلف همگانی خاموش/روشن` |

> دستورهای فارسی بدون پیشوند، انگلیسی با پیشوند `!` کار می‌کنند.
> فقط خودت (sudo) دسترسی داری.

## 🚀 راه‌اندازی روی گیت‌هاب (قدم به قدم)

### ۱) ریپو بساز — «Public» نه Private! ⚠️
- ریپو را **Public** بساز. چرا؟ سهمیه رایگان Actions:
  - ریپوی **Public** = دقیقه اجرا **نامحدود و رایگان** → ۲۴/۷ ممکن است ✅
  - ریپوی **Private** = فقط ۲۰۰۰ دقیقه در ماه → بات ۲۴/۷ حدود ۵۰,۰۰۰ دقیقه مصرف می‌کند → بعد از ~۱ روز تا ماه بعد خاموش می‌شود ❌
- **اما امنیت؟** سشن هرگز داخل کد نمی‌رود؛ فقط در **Secrets** قرار می‌گیرد و Secrets حتی در ریپوی Public هم رمزنگاری‌شده و مخفی هستند (در لاگ هم سانسور می‌شوند). پس Public بودن ریپو خطری ندارد.
- محتویات این پوشه را آپلود کن (پوشه مخفی `.github` را هم — راهش در پایین).

> **📁 نکته آپلود `.github`:** در صفحه ریپو → Add file → **Create new file** → در کادر اسم فایل بنویس: `.github/workflows/selfbot.yml` (خودش پوشه‌ها را می‌سازد) → محتوای فایل yml را Paste کن → Commit. بقیه فایل‌ها (`bot.py`, `config.py`, `framework.py`, `storage.py`, `utils.py`, `requirements.txt`, `gen_session.py` و پوشه `modules`) را با Upload files آپلود کن. اگر `selfbot.zip` را Extract کرده باشی، همه این فایل‌ها را داری.

### ۲) API بگیر
- برو به [my.telegram.org](https://my.telegram.org) → **API development tools**
- یک اپ بساز و `api_id` و `api_hash` را بردار.

### ۳) سشن بساز
روی کامپیوتر خودت:
```bash
pip install telethon
python gen_session.py
```
شماره و کد ورود را بده؛ کد ~۳۶۰ حرفی را کپی کن. (تو گفتی اینو داری ✅)

### ۴) Secrets را اضافه کن
در ریپو: `Settings → Secrets and variables → Actions → New repository secret`

| Name | مقدار |
|------|-------|
| `API_ID` | مثلا `1234567` |
| `API_HASH` | رشته api_hash |
| `SESSION` | سشن ۳۶۰ حرفیت |
| `SUDO` | آیدی عددی خودت (از @userinfobot) |
| `STORAGE_ID` | *(اختیاری ولی خیلی توصیه‌شده)* شناسه عددی یک کانال/گروه خصوصی که هر دو اکانتش عضو باشن؛ پایگاه داده و ذخیره‌ها اینجا می‌رن |
| `TZ_INFO` | `Asia/Tehran` (پیش‌فرض) |

> `STORAGE_ID` را با دستور `شناسه گروه` داخل همان کانال بگیر.

### ۵) اجرا
- تب **Actions** → روی ریپو برو → اگر پیام فعال‌سازی ("I understand my workflows, go ahead and enable them") آمد تأیید کن.
- **Selfbot** را از لیست ورک‌فلوها انتخاب → **Run workflow** → Run.
- بعد از ~۱ دقیقه وارد اجرا شو؛ باید ببینی: `اکانت #1 متصل شد ✅`
- از این به بعد هر ۵ ساعت خودش استارت مجدد می‌شود — دیگر نیازی به کاری نیست.

## ⏰ آیا واقعاً ۲۴ ساعته است؟

**بله ۲۴/۷ روشن می‌ماند،** با این مکانیزم:

- گیت‌هاب هر Job را حداکثر **۶ ساعت** اجازه اجرا دارد → ورک‌فلو بات را تا **۳۵۰ دقیقه** نگه می‌دارد و cron هر **۵ ساعت** یک اجرای تازه می‌سازد؛ اجرای قبلی تمام و اجرای جدید ادامه می‌دهد.
- نتیجه: پوشش پیوسته ۲۴/۷ با یک ری‌استارت کوتاه هر ۵ ساعت (چند ثانیه).
- تنظیمات بین ری‌استارت‌ها با پایگاه‌داده تلگرامی (`STORAGE_ID`) حفظ می‌شود — چیزی از دست نمی‌رود.
- سه محدودیت که باید بدانی:
  1. **تأخیر cron:** استارت خودکار گاهی چند دقیقه دیر می‌شود — طبیعی است.
  2. **ریپو Public** باشد تا دقیقه نامحدود بگیری (بالا توضیح داده شد).
  3. **خاموشی ۶۰ روزه:** اگر ریپو ۶۰ روز هیچ commit نداشته باشد گیت‌هاب زمان‌بند را خاموش می‌کند — ورک‌فلو یک استپ keepalive دارد که هر روز یک commit خالی می‌زند و جلوی این را می‌گیرد.

## 👥 چند اکانت داشتن

فقط برای هر اکانت یک Secret اضافه کن:

```
SESSION_1 = سشن اکانت اول
SESSION_2 = سشن اکانت دوم
SESSION_3 = سشن اکانت سوم   (تا ۸ تا)
```

- همه اکانت‌ها همزمان توی یک workflow ران می‌شوند و هرکدام تنظیمات مستقل خودشان را دارند.
- `SUDO` یکسان می‌ماند (آیدی خودت)، چون همه اکانت‌ها مال خودتی.
- همه اکانت‌ها باید عضو چت `STORAGE_ID` باشند تا تنظیمات‌شان ذخیره شود.
- برای هر اکانت جدا: `python gen_session.py` را با همان اکانت لاگین کن و خروجی را در `SESSION_2` و… بگذار.

## 🧠 پایگاه داده (مهم!)

GitHub Actions هر ۵ ساعت ری‌استارت می‌شود؛ پس تنظیمات (پاسخ‌های سریع، یادآورها، فیلترها و…) به صورت پیام فشرده در چت `STORAGE_ID` ذخیره می‌شود و در بوت بعدی دوباره خوانده می‌شود. **آن پیام «≡SFB-DB≡» را پاک یا ویرایش نکن!** اگر `STORAGE_ID` ندهی، تنظیمات فقط تا ری‌استارت بعدی می‌ماند.

---

## ⚠️ هشدارهای مهم

- سشن (کد ۳۶۰ حرفی) = **کنترل کامل اکانت تلگرامت**. آن را:
  - در چت به هیچ‌کس (حتی ربات‌ها) نفرست؛
  - داخل کد یا کامیت نگذار؛ **فقط** در GitHub Secrets بگذار (حتی در ریپوی Public امن است).
- ریپوی Public بساز تا دقیقه Actions نامحدود باشد؛ رازها فقط در Secrets می‌مانند.
- ران کردن یوزربوت ۲۴/۷ روی Actions طبق قوانین GitHub در ناحیه خاکستری است — ریپو را پرچم‌دار/پرریسک نکن و مصرف را متعادل نگه دار.
- استفاده زیاد از قابلیت‌های گروهی (تگ، پاکسازی حجیم) می‌تواند اکانت تلگرام را محدود کند. معقول استفاده کن.
- تلگرام سلف‌بوت را تأیید رسمی نمی‌کند؛ ریسک محدودیت اکانت همیشه هست.

## 🛠 عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| اجرای scheduled دیگر تریگر نمی‌شود | ریپو را ۶۰ روز بلافعالیت رها کردی — یک commit خالی بزن یا Run workflow دستی بزن (keepalive معمولاً خودش handle می‌کند) |
| بات وسط ماه خاموش شد (ریپوی Private) | سهمیه ۲۰۰۰ دقیقه تمام شده — ریپو را Public کن |
| `سشن نامعتبر` در لاگ | سشن منقضی/اشتباه است — دوباره `gen_session.py` بزن |
| ربات جواب نمی‌دهد | `وضعیت` بزن؛ لاگ Actions را ببین؛ چک کن اکانت خاموش نشده (`سلف همگانی روشن`) |
| ذخیره تنظیمات کار نمی‌کند | `STORAGE_ID` درست؟ اکانت عضو آن چت هست؟ |
| تگ/پاکسازی خطای دسترسی | اول اکانتت را ادمین گروه کن |

## 🛒 ربات فروشگاه «star self» (پوشه‌ی `shop/`)

ربات رسمی BotFather که سلف می‌فروشد: منوی ۱۰گانه، کیف پول، انتقال سکه، خرید سکه با کارت‌به‌کارت + رسید، فعال‌سازی با ساخت سشن داخل چت، تعرفه، زیرمجموعه و پنل ادمین کامل. جزئیات در [`shop/README.md`](shop/README.md).

**اجرا روی همین ریپو:** Secrets زیر را اضافه کن (Settings → Secrets and variables → Actions → New repository secret) و بعد workflow «Star Shop Bot» را Run کن:

| Secret | مقدار |
|--------|-------|
| `SHOP_BOT_TOKEN` | توکن ربات از BotFather |
| `SHOP_ADMIN_ID` | آیدی عددی ادمین |
| `SHOP_ENCRYPTION_KEY` | کلید Fernet (یک بار بساز: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`) |
| `SHOP_KEY` | کلید API سشن‌ها (هر رشته تصادفی) |
| `API_ID` / `API_HASH` | همان مال سلف (اگر از قبل داری، دوباره نگذار) |

دیتابیس SQLite در `shop/data/star.db` بین ران‌ها با commit خودکار ذخیره می‌شود؛ سشن و شماره مشتری‌ها داخلش با Fernet رمز شده‌اند (کلید فقط در Secrets است — در ریپوی عمومی هیچ‌چیز قابل خواندن نیست).

### ⚡ فعال‌سازی آنی (اتصال فروشگاه به سلف)
وقتی مشتری سلف می‌خرد:
1. ربات فروش همان لحظه پیام «✅ سلف شما فعال شد» را می‌فرستد و دیتابیس را فوراً به گیت پوش می‌کند.
2. سلف‌بات (که ۲۴/۷ روشن است) هر ۶۰ ثانیه گیت را چک می‌کند و سشن جدید را تا **حداکثر ~۲ دقیقه** بعد از خرید آنلاین می‌کند (قبلاً تا ۵ ساعت طول می‌کشید).
3. اتمام اعتبار/لغو از پنل ادمین → سلف مشتری به‌صورت خودکار و زنده قطع می‌شود.

سلف‌بات برای این اتصال فقط به همان Secret `SHOP_ENCRYPTION_KEY` نیاز دارد (در ورک‌فلو سلف ست شده). حریم خصوصی: هر مشتری فقط خودش روی سلفتش کنترل دارد.

## 🔧 آخرین فیکس‌ها (بازبینی کامل باگ)

- **پنل عکسی درست شد** (متد غلط تلتن `download_profile_media` → `download_profile_photo`)
- **مدیا بدون کپشن** حالا همه هوک‌ها را رد می‌کند: آنتی‌حذفِ عکس/ویدیو، ذخیره TTL، پاسخ سریع روی استیکر، مدریه استیکر — همه کار می‌کنند
- **تنظیمات دیگر گم نمی‌شود**: ایندکس ذخیره‌سازی پین می‌شود + جستجوی عمیق؛ ذخیره‌های هم‌زمان قفل شدند؛ موقع SIGTERM دیتابیس flush می‌شود
- **حذف خودکار روشن** (`حذف روشن 5`) دیگر خطا نمی‌داد (NameError)
- آنتی‌حذف: تداخل آیدی پیام بین چت‌ها رفع شد؛ دستورها دیگر ابرروی‌کلمه‌ای تطبیق نمی‌شوند (`!onto` دیگر `on` را نمی‌زند)
- وایس/ffprobe در thread جدا — هنگ‌کردن ربات موقع تبدیل صدا رفع شد؛ چک قفل عکس گروه هر ~۳ دقیقه (فلود رفع شد)
- **فروشگاه**: کد ورود فارسی/فاصله‌دار پذیرفته می‌شود؛ کد منقضی خودکار تازه می‌شود؛ گیت‌واوت و بازگشت سکه‌ها دقیق شد؛ گارد دابل‌کلیک (دو بار کسر سکه غیرممکن است)؛ خروج وسط جریان سکه را برمی‌گرداند؛ تمدید خودکار ناموفق سکه را برمی‌گرداند؛ رسید اتمیک (دابل‌واریز ندارد)؛ شماره مشتری‌ها هم رمز شد
- **سلف**: SIGTERM حالا واقعاً flush می‌کند؛ کلاینت مرده مشتری خودش دوباره بالا می‌آید؛ تغییر سشن بدون ری‌استارت اعمال می‌شود؛ فچ فروشگاه دیگر ربات را فریز نمی‌کند؛ مقصدهای سیو چنل/ست لاگ بعد از ری‌استارت هم کار می‌کنند
